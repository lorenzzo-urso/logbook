Despite Large Language Models (LLMs) absorbing most of the interest today with narratives like ‘agents’, one of the most exciting AI research papers lately has nothing to do with them.

And what’s at stake? Personalized healthcare, something the industry has been envisioning for years with little to show for.

But this could be different and could open the door for a more sustainable economy. Here’s why.

Not All is About Text and Code

The simplest way to describe AI is as models that learn patterns in data and make predictions about similar data.

An AI sees a lot of housing data and can make predictions about the prices of new homes
An AI sees a lot of text and learns to write new text (e.g., GPT, Claude)
An AI sees a lot of code and learns to write new code (e.g., GPT Codex models)

Today, most value and attention are concentrated in AIs that “live” in the realms of text (LLMs) and code (coding agents, which are still LLMs).
